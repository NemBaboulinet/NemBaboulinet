## <img src="assets/rocket.svg" width="22" height="22" align="center" alt="" /> Projets

### Évolution d'une plateforme industrielle IoT — Stage de fin d'études (DOWNS)
*React • TypeScript • Tailwind CSS • Jotai • Zod • Highcharts • Ant Design • Docker*

Conception et développement de fonctionnalités Full-Stack pour la plateforme **SAALTO**, spécialisée dans la centralisation et la valorisation de flux de données issus de capteurs IoT.
* **Architecture front-end :** interfaces dynamiques et scalables, gestion d'état atomique (`Jotai`).
* **Fiabilisation des données :** validation stricte des schémas (`Zod`) pour sécuriser les échanges avec l'API.
* **Data visualisation :** tableaux de bord analytiques (`Highcharts`) pour le suivi client en temps réel.
* **Environnement standardisé :** Docker et DevContainers pour isoler l'environnement de développement.

### Infrastructure multijoueur dédiée — DevOps & self-hosting
*Linux (Ubuntu) • Docker • Docker Compose • Bash • Réseau (port forwarding, LAN/WAN) • Sauvegardes automatiques • Webhooks Discord*

Mise en place et maintenance de serveurs de jeux persistants conteneurisés, orientés résilience et automatisation.
* **Conteneurisation :** isolation des services et gestion des volumes pour la persistance des données.
* **Automatisation (Bash) :** scripts de gestion du cycle de vie des conteneurs et sauvegardes à chaud planifiées.
* **Réseau & monitoring :** routage (port forwarding, NAT/PAT), sécurisation des accès et notifications d'état par webhooks Discord.

### Outil d'export des statistiques du portfolio
*Bun • JavaScript • API Vercel Web Analytics • ExcelJS*

Script autonome qui récupère les visites du portfolio (visiteurs, pages vues, sources, pages, pays), les historise jour par jour dans un fichier Excel et génère un tableau de bord HTML.
* **Mise à jour incrémentale :** recalcul des derniers jours pour rattraper les jours manquants, sans doublons.
* **Sécurité :** aucun secret dans le code, configuration par variables d'environnement, fichiers de données exclus de Git.
